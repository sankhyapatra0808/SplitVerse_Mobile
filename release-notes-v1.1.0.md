## SplitVerse v1.1.0

### What's New

- Added a completely redesigned SplitVerse onboarding experience.
- Added responsive landing-page controls across different phone sizes.
- Improved email signup and OTP onboarding flow.
- Username selection now happens during final account setup.
- Added dedicated Wallet Security setup page.
- Improved Wallet PIN keyboard handling.
- Strengthened Privacy Mode with native screenshot and screen-capture protection.
- Improved Friends UI with a compact send-request action.
- Added various UI, stability, and usability improvements.

### Privacy

When Privacy Mode is enabled:
- Screenshots are blocked.
- Screen recording is protected.
- Screen sharing is protected.

### Installation

Download `SplitVerse-v1.1.0.apk` from the Assets section below and install it on your Android device.
